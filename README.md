# Violet Wire test builds

This repository publishes versioned hardware test snapshots. Development, tests and issues live in [wronghands/violet-wire](https://github.com/wronghands/violet-wire).

- [Effect 58 · v2](https://wronghands.github.io/violet-wire-tests/effect-58-v2/lab/) is the English physical observation experiment for a red–green preset at minimum speed. Stationarity and independent addressing on the target remain unverified. [Exact canonical source](https://github.com/wronghands/violet-wire/tree/02f50a834811823c39ab2a637691d9e2bd87dc9b) · [Hardware QA](https://github.com/wronghands/violet-wire/blob/02f50a834811823c39ab2a637691d9e2bd87dc9b/docs/STATIONARY_COLORS.md)
