# Violet Wire test builds

This repository publishes versioned hardware test snapshots. Development and issues live in [wronghands/violet-wire](https://github.com/wronghands/violet-wire).

- [Color Breathing · v1](https://wronghands.github.io/violet-wire-tests/color-breathing-v1/lab/) cycles two global colors with optional brightness pulsing. [Exact source](https://github.com/wronghands/violet-wire/tree/bac89d2ad8479ec34e10bf65fdb47a6ded79bf53) · [Physical QA](https://github.com/wronghands/violet-wire/blob/bac89d2ad8479ec34e10bf65fdb47a6ded79bf53/docs/COLOR_BREATHING.md)
- [Effect 58 · v3](https://wronghands.github.io/violet-wire-tests/effect-58-v3/lab/) compares two speed inputs on a built-in two-color preset. [Exact source](https://github.com/wronghands/violet-wire/tree/a86f4877a0b904907008f15ec21ae8d3444db75c)
- [Effect 58 · v2](https://wronghands.github.io/violet-wire-tests/effect-58-v2/lab/) is the original English minimum-speed experiment. The owner observed both colors and continued motion. [Exact source](https://github.com/wronghands/violet-wire/tree/02f50a834811823c39ab2a637691d9e2bd87dc9b)

Each version directory includes its own transport modules. Keep published directories intact and add new experiments at new paths. The stable app has a separate Pages deployment.
