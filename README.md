# Violet Wire test builds

This repository publishes versioned hardware test snapshots. Development, tests and issues live in [wronghands/violet-wire](https://github.com/wronghands/violet-wire).

- [Effect 58 · v1](https://wronghands.github.io/violet-wire-tests/effect-58-v1/lab/) is a physical observation experiment for a red–green preset at minimum speed. Stationarity and independent addressing on the target remain unverified. [Exact canonical source](https://github.com/wronghands/violet-wire/tree/a34872c0144651e27cb6e8cec92e9e198364bacd) · [Hardware QA](https://github.com/wronghands/violet-wire/blob/a34872c0144651e27cb6e8cec92e9e198364bacd/docs/STATIONARY_COLORS.md)
